# 考研打卡系统

2027 考研每日打卡系统 - Python Flask Web 应用

## 功能特性

- 📅 **每日打卡**：数学二、英语二、408、政治四科打卡记录
- 📊 **阶段进度**：五个备考阶段进度可视化（基础→强化→暑假→真题→冲刺）
- 🔥 **热力图**：90 天打卡热力图，支持点击查看每日详情
- 📱 **手机访问**：支持局域网内手机浏览器访问
- 🌙 **深色主题**：护眼深色界面设计

## 文件说明

| 文件 | 说明 |
|------|------|
| `kaoyan_core.py` | 核心逻辑（阶段计算、数据统计） |
| `kaoyan_web.py` | Flask Web 服务 |
| `打卡页面.html` | 前端页面（手机优先设计） |
| `考研打卡.bat` | Windows 双击启动脚本 |
| `考研打卡.pyw` | Python 静默启动器 |

## 使用方法

### 1. 启动服务

双击 `考研打卡.bat` 启动服务，自动打开浏览器访问 `http://127.0.0.1:5050`

### 2. 手机访问

确保手机和电脑在同一 WiFi 下，手机浏览器访问：
```
http://<电脑IP>:5050
```
电脑 IP 可在启动后的命令行窗口中查看。

### 3. 数据存储

打卡数据保存在 `~/.kaoyan_checkin/records.json`，重装系统前请备份此文件。
